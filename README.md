# Pizzas_Sales_SQL
# 🍕 Pizza Sales Analysis Using SQL

This project analyzes pizza sales data using **SQL** to understand sales performance, customer ordering patterns, and product trends.

## 📌 Project Objective

The main objective of this project is to analyze pizza sales data and generate meaningful business insights using SQL queries.

## 🛠️ Tools & Technologies

* SQL
* MySQL
* Database Management
* Data Analysis

## 📊 Analysis Performed

* Calculated total revenue and total number of orders
* Analyzed total pizzas sold
* Identified the best-selling pizzas
* Analyzed sales by pizza category
* Analyzed sales by size
* Found peak ordering days and hours
* Calculated average order value
* Identified top-performing pizza categories
* Analyzed daily and monthly sales trends
* Used SQL **JOIN, GROUP BY, ORDER BY, WHERE, HAVING, aggregate functions, subqueries, and window functions**

## 💡 Key Insights

The analysis helps identify:

* Which pizzas generate the highest revenue
* Which pizza sizes are most popular
* Which categories contribute the most to sales
* When customers place the most orders
* Overall sales and revenue trends

## 🎯 Skills Demonstrated

This project demonstrates practical knowledge of **SQL querying, data analysis, aggregation, joins, filtering, grouping, and business insight generation**.
